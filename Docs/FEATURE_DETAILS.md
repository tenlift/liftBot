# 侧伴 · TenLift.ai

一个使用 SwiftUI + AppKit 构建的原生 macOS 侧边工作台，集合笔记、待办、专注和录音。

采用本地 Swift Package 模块化架构，详见 [架构说明](Docs/ARCHITECTURE.md) 和 [贡献指南](CONTRIBUTING.md)。项目采用 MIT 许可证，详见仓库根目录 LICENSE。

## 运行

使用 Xcode 打开 `侧伴/侧伴.xcodeproj`，选择 macOS 运行目标。最低部署版本为 macOS 14；当前已使用 Xcode 27.1 完成 Debug 编译（未签名）。如需签名运行，请在 Signing & Capabilities 中选择自己的开发团队。

## 当前能力

- 原生材质与系统颜色，适配深色和浅色外观。
- 侧栏窗口：拖动至屏幕可用区域左右边缘 24 点内会吸附，默认自动收起为 52×164 点图文标签；点击标识恢复。顶部有置顶图钉及手动收起按钮，收起按钮右键菜单可选择左右停靠、关闭自动收起或取消吸附。置顶时保持展开并显示在普通窗口之上；未置顶的已吸附窗口失去焦点后自动收起。
- 顶部按中国大陆周一至周日计算距本周首个休息日的日历天数与周内休息总天数；普通周末、法定节假日和调休工作日分别处理，点击查看七天明细。当前离线内置 2026 年官方安排；缺少年份会明确标注按双休估算，可在设置导入年度 JSON。
- 专注时长放大加粗，休息时长缩小，同时展示，默认 25 / 5 分钟。未开始或重置后，双击分钟、秒数原位修改，回车或移开焦点保存，Esc 取消；无效输入恢复原值；点击模式名称切换。分钟范围 0–180，秒数范围 0–59，总时长需大于零。
- 右侧纵向开始 / 暂停和重置按钮。设置 → 快捷键中点击输入框后直接按组合键，可分别自定义开始 / 暂停专注、开始 / 结束录音和快速打开侧边栏；松开按键保存，Esc 取消、Delete 或清除按钮停用。应用运行期间全局生效，不需要辅助功能权限。默认分别为 ⌃⌥P、⌃⌥R、⌃⌥空格；保留旧版手动选择的 ⌘⇧P / ⌘⇧T，旧版空格设置迁移为 ⌃⌥P。录入期间暂停全局动作；重复、常用编辑键和系统占用的组合会提示，不覆盖原设置。
- 计时以结束时间计算，避免普通定时器累计误差；结束时发出系统提示音。暂停后需重置才能修改时长，重置保留当前模式。
- 待办添加、编辑、完成与删除；右侧铃铛可设置日期时间、10 分钟后或 1 小时后提醒，也可移除提醒。时间保存在本机，旧待办自动兼容。
- macOS 本地系统通知：首次设置待办提醒或开始番茄钟时申请通知权限。待办到时、专注 / 休息结束时显示通知并使用系统通知声音，应用在前台也可显示。暂停、重置、完成、删除或移除提醒会取消对应的待发送通知。已成功安排的通知由系统调度，应用不运行时也可送达；实际展示遵循通知权限与系统专注模式。
- 设置中可启用通知、打开系统通知设置；应用重新激活后刷新授权状态。调度失败会显示提示，不会把失败当作已安排。
- Note 右上角可展开 / 收起；展开后番茄钟、录音和未完成待办数量压缩为一排，为长内容留出空间。切换布局不销毁计时器或录音状态，压缩模式支持直接开始 / 暂停计时与开始 / 停止录音。
- Note 多 Tab：新增、切换、编辑页名和选择六种标签颜色，内容与选中页保存在本机；旧版单页笔记自动迁移。
- Note 录音附件和正文使用同一个纵向滚动区域；编辑器随内容增高，不再为附件或正文单独设置滚动区域。页面颜色应用到整张 Note 卡片，以平铺的真实色块切换，支持深浅外观。
- Markdown 源码编辑和原生预览：标题、列表、任务项、引用、代码块、加粗、斜体和链接。预览暂不渲染表格和远程图片。
- 设置中通过系统文件夹选择器授权 Obsidian 仓库；持久化 security-scoped bookmark。
- 支持从 Finder 拖入多个普通文件到主界面，复制到附件目录，按设置追加到当前 Note 页面或新建一张 Note；默认新建。收起状态也可将文件拖入边缘标签，自动展开并遵循相同设置。同一次拖入的多个文件放入同一张新笔记，原笔记和原文件保留，切换 Tab 不会改变目标页。附件可点击打开，文件夹和符号链接暂不支持。
- 设置可分别选择本机文件附件、录音目录，使用持久化目录授权；目录更改影响新附件，旧目录继续保留访问。也可分别设置 Obsidian 内普通附件和录音附件的相对路径，默认 Sidebar/Attachments 与 Sidebar/Recordings。
- Note 的保存按钮只导出当前笔记的 Markdown 原文到 `Sidebar/`，不添加外层标题、时间或待办列表；文件名使用页面名称及唯一后缀。
- 待办标题旁有独立保存按钮，导出到 `Sidebar/Tasks/` 下的独立 Markdown 文件，保留完成状态与提醒时间。两种保存互不混入内容，重复保存生成新快照，不覆盖文件。

- 快捷录音：首次使用申请麦克风权限，实时计时及音量显示，停止后自动保存 AAC 编码的 `.m4a` 到应用的 Application Support/Recordings。历史录音支持回放及 Finder 定位。停止后按设置加入当时的 Note 页面或新建并切换到录音笔记，默认当前页；转写队列始终向录音所在页面追加结果，不覆盖期间的手动编辑。
- 语音转文字：系统 Speech 框架，默认普通话，设置中可改为英语；仅使用本地识别，需系统权限及对应语言资源。macOS 26 及以上在设备和语言受支持时优先使用 SpeechAnalyzer，并通过 AssetInventory 准备语言模型；首次可能由系统下载资源。旧系统保留 SFSpeechRecognizer 路径。未增加应用通用出站网络权限。不支持本地识别、无语音、失败或超时时保留音频，可在 Note 中重试。应用重启后未完成的识别显示重试状态。
- 导出当前 Note 时会一并复制其录音附件到 `Sidebar/Recordings/`，保留 Markdown 内的音频嵌入引用。
- 录音导出：在录音记录中手动保存音频与带嵌入链接的 Markdown 到 `Sidebar/Recordings/`，重复导出同一段音频不会复制多份。本机原始录音保留。

## 界面语言

在设置的「语言 / Language」中选择「跟随系统」「简体中文」或「English」。选择会自动记住并立即更新界面、菜单和后续提示，无需重启；笔记、待办原文和语音识别语言保持不变。默认跟随系统，不支持的系统语言使用英文。

切换时会更新应用当前管理的待办和番茄钟提醒文案，并保留提醒时间。应用启动前已交给系统、且当前进程不再管理的提醒保留原文。系统权限弹窗由 macOS 选择语言，可能需要系统设置或重新启动应用后才更新。

## 代码结构

应用源码按 App、Features、Platform、Workspace 分组；纯模型与窗口几何规则位于 `Packages/SidebarCore`。下列为各文件职责，完整路径见架构说明。

- `ContentView.swift`：主界面与待办、速记交互。
- `PomodoroTimer.swift`：应用级共享计时状态、隐藏视图时的计时完成处理和通知同步。
- `PomodoroView.swift`：主界面的计时卡片。
- `SidebarQuickControls.swift`：收起标识的悬浮快捷控制。
- `WorkspaceStore.swift`：草稿模型、本机持久化、仓库授权和 Markdown 导出。待办按固定 ID 在副本上更新后统一发布，避免删除闭包再次读取数组绑定引发 Swift 独占访问冲突。
- `SettingsView.swift`：仓库设置。
- `SidebarWindowController.swift` / `SidebarGeometry.swift`：自身窗口的置顶、吸附、边缘标识和多屏坐标计算，不使用辅助功能权限或全局事件监听。
- `StorageLocations.swift` / `FileDropSupport.swift`：目录授权、导入复制、附件引用与仓库内路径检查。
- `HolidayCalendar.swift` / `WeeklyRestView.swift`：年度日历、周一至周日计算和休息日展示。
- `NotificationService.swift`：本地通知授权、前台通知展示、串行调度与取消；可注入模拟后端。
- `TaskReminderView.swift`：待办提醒编辑器。
- `SidebarApp.swift`：场景与共享数据注入。
- `RecordingStore.swift`：麦克风授权、录音、音量计量、本机文件及播放生命周期。
- `RecordingView.swift`：录音卡片及历史列表。
- `NotePage.swift` / `NotesView.swift`：笔记数据模型、多彩标签页、附件状态和 Markdown 预览。
- `NoteTextEditor.swift`：无独立滚动容器、根据内容和宽度自动测量高度的原生文本编辑器。
- `SpeechTranscriber.swift`：可注入的本地语音识别服务与超时保护。

没有引入第三方依赖。用户草稿及仓库路径不存入项目目录。

## 回归检查

运行 `bash Tests/run-workspace-checks.sh`。使用隔离的 UserDefaults suite、临时音频目录和模拟识别器，不访问麦克风或真实 Obsidian 仓库。检查旧笔记迁移、自动附件插入、切换 Tab 后转写归属、识别失败与重试、标签页持久化，以及 Markdown 与音频导出。通知回归使用模拟后端，覆盖权限拒绝、重新授权、待办变更、完成与删除、番茄钟暂停 / 重置，以及异步安排期间的取消竞态。尚未完成真实 macOS 横幅和声音的实机验收。

## 转写错误恢复

`kAFAssistantErrorDomain / 1101` 表示与语音进程的连接失效，不代表录音文件损坏。新系统优先使用新的本地引擎及显式资源准备；旧系统可检查「系统设置 → 键盘 → 听写」中的语言资源及语音识别权限。Note 附件保留错误详情，并提供「重试」和「帮助」。当前未在用户设备上验证新引擎能否消除该错误。

依据：[Apple 语音任务错误码](https://developer.apple.com/documentation/speech/sfspeechrecognitiontask/error)、[SpeechAnalyzer](https://developer.apple.com/documentation/speech/speechanalyzer)、[AssetInventory](https://developer.apple.com/documentation/speech/assetinventory)。

## 附件与节假日日历

本机附件默认在应用 Application Support 下的 Attachments 和 Recordings；可在设置分别选择其他目录。选择新目录不会搬走旧文件。Obsidian 附件目录是相对于仓库根目录的路径，不允许绝对路径、`..` 或通过符号链接越出仓库。文件导入在后台复制，文件名加入唯一后缀，避免同名覆盖。

2026 年放假及调休依据国务院办公厅《国办发明电〔2025〕7号》；[官方来源](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)。规则仅针对中国大陆标准周一至周五工作制，不覆盖个人单休、轮班或公司自定义安排。本周休息天数是周一至周日范围内的总数，不表示连续假期天数。每日时间以 Asia/Shanghai 为准。

年度日历格式见 `Examples/holidays-2026.json`：year 为年份，source 为来源，days 中列出覆盖常规周末规则的日期；isOff=true 表示休息，false 表示调休上班，日期使用 YYYY-MM-DD。设置中可导入后续年度数据。当前没有运行时联网更新，缺失年度不伪装为已核对的官方安排。

回归新增：旧笔记附件字段迁移、文件复制保留原件、跨 Tab 归属、可配置导出位置、路径越界及符号链接检查、普通周末、周末调休、跨周国庆安排、缺失年度估算、日历导入与持久化。原生 Finder 拖放和外部目录授权仍需在签名运行的应用里实机验收。

待办回归覆盖实际行操作：移除提醒保留任务并取消对应通知、编辑与完成、删除后过期回调不恢复任务，以及保留其他待办及其通知。

## 窗口控制说明

主界面使用单个 Window 场景，避免重复侧栏争用计时器或吸附标识。收起通过 orderOut 隐藏窗口，而不关闭窗口或移除 SwiftUI 内容，保留笔记、计时和录音状态。边缘标识使用固定尺寸的原生 NSButton 和独立非激活面板，不依赖 SwiftUI 浮层尺寸，也不参与 AppKit 浮动工具面板的隐藏机制。首次点击即可展开，右键可取消吸附。先确认标识可见再隐藏主窗口；若标识显示失败则保留或恢复主窗口。菜单栏“显示随手记”和 Dock 应用重开均可恢复窗口。

置顶及自动收起偏好会记住。拖动结束后才执行吸附，弹出系统对话框、设置 sheet、窗口实时缩放和自身全屏时不会主动收起。显示器变化后按可用屏幕区域重新约束位置。几何回归覆盖左右边缘、普通非边缘移动、菜单栏区域、负坐标副屏、标识可点击范围和较小屏幕；已在运行的 Debug 应用中人工验证左右收起、边缘标识可见及重复点击展开；跨空间置顶、多屏和关闭主窗口后的恢复尚未全部自动化验收。窗口控制器由 App 持有，不随主视图暂时卸载而清除边缘标识。

## 收起后的活动状态与快捷操作

边缘标识上方以橙色火焰 / 绿色咖啡杯区分专注和休息，暂停显示暂停图标；录音中下方显示红色麦克风并轻微呼吸闪烁。两种活动可同时展示。系统工具提示与辅助功能标签也提供当前模式和计时信息。

鼠标悬浮约 180ms 后显示快捷面板，包含倒计时、开始 / 暂停 / 继续 / 结束计时、快速切换到专注或休息、开始 / 停止录音以及展开侧栏。指针在标识和面板之间移动有宽容区，离开后延迟收起。面板有关闭按钮，也可通过标识右键菜单打开快捷控制以便键盘操作。

收起和展开使用短距离滑动与淡入淡出，悬浮面板同样带过渡。遵循系统“减弱动态效果”设置。计时状态由 WorkspaceStore 持有，主窗口、悬浮面板和原生标识使用同一状态；完成计时不依赖可见的 SwiftUI TimelineView。

已通过共享计时器与通知生命周期回归，并在隔离原生测试应用中验证专注标识、倒计时、快捷面板暂停 / 继续 / 结束、开始休息以及恢复窗口。窗口可见性采样确认存在动画中间帧。本轮未调用真实麦克风。

### 界面外观（2026-10-28）

采用原生材质背景、圆角卡片和语义颜色。设置中的外观选项支持跟随系统、浅色、深色，选择自动记忆并应用到窗口与快捷面板。收起后显示番茄钟、录音、Note 图文标签；点击展开，悬停继续使用快捷控制，运行中的计时和录音保留状态提示。

### 蓝青毛玻璃外观

主界面、设置、录音记录和悬浮快捷面板使用统一的蓝青渐变底色与原生毛玻璃。浅色偏雾蓝和薄荷青，深色偏海军蓝和深青；卡片使用半透明材质与轻描边，笔记仍保留各自的标签色。模糊只用于背景装饰，不作用于文字或控件；开启系统「降低透明度」时使用不透明底板。

收起标签现为 52×164 点；原生毛玻璃使用独立圆角遮罩，避免仅裁切普通图层时圆角外露出材质底色。

悬浮快捷面板已收窄为 240×210 点，与停靠几何规则共用尺寸常量。应用图标使用 `Design/AppIcon/ceban-icon-v1.png`，已生成 macOS 标准 AppIcon 尺寸并接入构建。

### 自定义全局快捷键实现与验收

`Platform/Shortcuts` 使用 Carbon RegisterEventHotKey 注册用户选定的组合键，并提供应用内事件回退，不监听其他应用的普通按键。快捷键独立存储到 `keyboardShortcuts.v1`；冲突时保留旧配置，清除后不会在重启时自动恢复。按键按下 / 松开共用状态，避免长按重复开关。

`bash Tests/run-workspace-checks.sh` 覆盖配置保存、迁移、冲突回滚、录入期间暂停和动作分发。在有桌面会话的 macOS 上可执行 `RUN_NATIVE_SHORTCUT_CHECKS=1 bash Tests/run-workspace-checks.sh`，额外验证原生热键注册、系统占用、Carbon 回调和释放去重。原生输入框已手动验证直接按键录入、三个动作分发、重复提示、Esc 取消及 Delete 清除，录音动作使用隔离计数器验收，未调用真实麦克风。

### 录音与文件的笔记去向

设置 → 笔记保存方式，分别选择「录音完成后」和「拖入文件时」保存到「当前笔记」或「新笔记」。两项独立记忆，未设置时沿用旧行为：录音为当前笔记，文件为新笔记。

录音以停止时的设置和当前页为准；新笔记按录音时间命名，转写与重试仍归属录音所在页。文件在放下时固定设置和目标页，同次多个文件进入同一页；读取拖放数据或复制文件期间切换标签页不会改变归属。若读取拖放数据期间原目标页被删除，会新建笔记接收文件，避免误写入其他笔记。
